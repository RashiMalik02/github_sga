About the Assignment

This project was created for the Git & GitHub Workflow and Test Case Design assignment. It is a simple two-page website, and it is used to demonstrate a complete version control workflow: creating a repository, making commits, working on a separate branch, merging, ignoring files, undoing a commit and finally publishing everything to GitHub.

Project Features

The repository behind this website demonstrates the following Git features:

  • Local repository – initialised with git init on the main branch.
  • Commits – each meaningful change is saved with a descriptive message.
  • Feature branch – this section was written on a separate feature branch.
  • Merging – the feature branch was merged back into main.
  • .gitignore – log files and the temp/ folder are excluded from tracking.
  • Remote hosting – both branches are published to a public GitHub repository.
