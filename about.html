About the Assignment

This project was created for the Git & GitHub Workflow and Test Case Design assignment. It is a simple two-page website, and it is used to demonstrate a complete version control workflow: creating a repository, making commits, working on a separate branch, merging, ignoring files, undoing a commit and finally publishing everything to GitHub.
