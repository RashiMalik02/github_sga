My command log for the SGA, in the order I needed each one.

[setup]
git init -b main                    -> made my site folder a repo, branch called main from the start
git branch --show-current           -> double-checked I was sitting on main

[saving work]
git add index.html about.html       -> picked both pages for my very first snapshot
git commit -m "..."                 -> wrote each snapshot into history with a message (11 times overall)
git diff --stat                     -> saw my homepage edit was 16 lines before I staged it
git diff --cached --stat            -> after the soft reset, proved my 9 lines were still waiting to be committed

[branches]
git branch feature                  -> opened a side line called feature
git checkout feature                -> hopped over to it to edit about.html
git checkout main                   -> hopped back so I could merge
git branch / git branch -a          -> listed branches, * shows where I am

[merge]
git merge --no-ff feature           -> pulled feature into main and forced a real merge commit (d949bc2)

[looking around]
git status                          -> my "what's going on" command, used constantly
git log --oneline                   -> compact list of snapshots
git log --oneline --graph --all     -> drew the fork and the join as ASCII art

[ignoring]
git check-ignore -v <files>         -> showed which .gitignore line caught debug.log, error.log and temp/notes.txt

[undo]
git reset --soft HEAD~1             -> pulled 523a07d off main locally, kept its lines staged
git revert --no-edit HEAD           -> cancelled bf5012b with a new opposite commit (65dbd78) that GitHub shows

[github]
git remote -v                       -> printed where origin pointed, before and after
git remote remove origin            -> dropped a stale link to a repo I had deleted
git remote add origin <github_sga>  -> linked to github_sga, made after my local commits existed
git push -u origin main             -> first upload of main, remembers the target
git push -u origin feature          -> same for feature
git push                            -> later uploads of main
git ls-remote --heads origin        -> asked GitHub for its branch tips; matched mine
