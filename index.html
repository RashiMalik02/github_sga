What is Version Control?

Version control is a system that records changes to files over time so that specific versions can be recalled later. Git is a distributed version control system, which means every developer has a full copy of the project history on their own machine. GitHub is an online platform that hosts Git repositories and makes it easy to share code and collaborate.

The Basic Git Workflow

Most day-to-day work with Git follows the same cycle:

  1. Modify files in the working directory.
  2. Stage the changes that should be saved using git add.
  3. Commit the staged snapshot with a clear message using git commit.
  4. Push the commits to a remote repository such as GitHub using git push.

Branches allow new work to be developed separately from the main line of the project. Once a feature is complete, its branch is merged back into main.
